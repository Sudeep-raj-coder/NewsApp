# 📰 NewsApp

A responsive News Application built with **React.js** that displays the latest news using the **NewsAPI**. Users can browse news by category, search for articles, switch between English and Hindi, and enjoy infinite scrolling for a better reading experience.

---

## 🚀 Features

- 📰 Latest news articles
- 🔍 Search news by keyword
- 📂 Browse news by category
  - All
  - Politics
  - Crime
  - Education
  - Technology
  - Science
  - Sports
  - Cricket
  - IPL
  - Entertainment
  - Jokes
- 🌐 Language switch (English / Hindi)
- ♾ Infinite Scroll
- 📱 Fully Responsive Design
- 🖼 Fallback image when news image is unavailable

---

## 🛠 Technologies Used

- React.js
- JavaScript (ES6)
- Bootstrap 5
- React Router DOM
- React Infinite Scroll Component
- NewsAPI

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/newsapp.git
```

### 2. Go to the project folder

```bash
cd newsapp
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```

## 📖 How It Works

- Users can browse different news categories.
- News articles are fetched from NewsAPI.
- Users can search news using the search bar.
- Infinite scrolling automatically loads more articles.
- Users can switch between Hindi and English news.

## 🔑 API Used

NewsAPI

```
https://newsapi.org/
```

Example Endpoint

```
https://newsapi.org/v2/everything?q=technology&language=en&pageSize=20
```
